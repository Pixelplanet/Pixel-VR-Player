## Pixel VR Player v1.12.2 — library artwork

Installer-only update; the player is the same as
[v1.12.0](https://github.com/Pixelplanet/Pixel-VR-Player/releases/tag/v1.12.0).

### 🖼 Icon and artwork in the Steam library
- The installer puts Pixel VR Player's icon, capsule, banner, hero and logo into your Steam
  library — but Steam only loads custom artwork when it starts, and on the Steam Frame
  switching between Desktop and Gaming Mode doesn't restart it. The installer now notices
  this and **asks whether to restart Steam** at the end; choose **Yes** and the artwork
  appears (or just reboot later).
- The library icon is now a proper 256×256 image.
- The install / update windows show their final message themselves (one click on **OK** /
  **Yes** / **No**); errors still show the last lines of `~/pixelvr-install.log`.

> [!NOTE]
> Already installed v1.12.0 / v1.12.1 and the library shows no artwork? It is already on
> disk — restart Steam once (or reboot the headset).

SFTP and WebDAV shares (new in v1.12.0) are still untested on real servers — please
[report problems](https://github.com/Pixelplanet/Pixel-VR-Player/issues).
