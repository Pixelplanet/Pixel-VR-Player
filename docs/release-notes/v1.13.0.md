## Pixel VR Player v1.13.0 — straight into the player

### 🚀 No more "Resume Game" at launch
- Starting the player from the Steam library now works like a Steam VR game: SteamVR shows
  **Up next** with the player's artwork and drops you straight into it. Before, every launch
  stopped on the **Resume Game** screen until you pressed it.
- The player also starts much faster: about 1 second from launch to the first frame
  (was about 4.5 seconds).
- The installer now turns on **Include in VR Library** for the Steam shortcut. If Steam was
  running, it asks to restart Steam once to apply it.

> [!NOTE]
> If the first launch after updating still shows **Resume Game**, press it once; the launches
> after that go straight in.

### 🪟 Panels
- **Panel Style** (Settings → UI & Appearance) has real **Solid**, **Frosted** and **Glass**
  options. Frosted blurs every screen behind a panel, not just the selected one.
- Click feedback on buttons, and panels animate closed.
- Sharper thumbnails in the file browser.

### 🖥 Screens
- **Screen glow** now surrounds every screen, browser screens included, without spilling onto
  neighbouring screens. **Glow Around** (Selected Screen / All Screens) appears under Ambient
  Screen Glow when Multiple Screens is on.
- **Screen numbers** replace the screen outlines: the dock button shows a number in the
  middle of each screen, and numbers appear by themselves while screens are unlocked for moving.
- **Room** (Settings → Display & Cinema): Midnight (the old navy), Black, Slate or Warm
  around the screens.

### 🎮 Controls
- **Laser Smoothing** (Settings → Controls & Input): Off / Low / Medium / High, default
  Medium. The laser no longer shakes with your hand, but still follows fast moves.
- The **volume bar** can be clicked or dragged. The mute button in the multi-screen row is
  gone; the speaker icon on the volume pill mutes.
- **Keyboard**: a PC-style layout (number row, Enter on the home row, two Shift keys) and five
  layouts: US, Deutsch, UK, Français (AZERTY) and Nordic.

### 📥 Downloads
- Plex downloads go through the player's Downloads window, with the file name from the server.
  **Download Folder** (Settings → UI & Appearance) picks where they go.
- **Play** in the Downloads window asks which screen to use, like the file browser.

### 🔧 Fixes
- The thumbstick no longer nudges a browser screen while you scroll a menu on its page
  (for example Plex's "…" menu).
- **B** on a shortcut's start page no longer goes back to an empty page.
- Updates now run the new release's own installer, so installer fixes apply on the same update.

SFTP and WebDAV shares are still untested on real servers — please
[report problems](https://github.com/Pixelplanet/Pixel-VR-Player/issues) with your server
type, what you did, and `~/pixelvr-run.log`.
