## Pixel VR Player v1.8.0 — Glass UI, curved panel & new keyboard

A big visual and usability update: the whole interface was redesigned to match the concept
mockups, with a curved, see-through glass panel, a new built-in keyboard, and a set of
long-requested playback features.

### ✨ New look
- **Glass interface:** panels are now translucent glass with a soft bevel and a subtle
  reflection that moves as you move your head. Choose how see-through it is in
  **Settings › UI & Appearance › Panel Transparency** (Solid / Frosted / Glass / Clear).
- **Curved main panel:** the menus, the playback controls and the pop-up windows can wrap
  around you. **Settings › UI & Appearance › Main Panel Shape** (Flat / Gentle / Wrap).
- **New font:** the bundled Inter typeface, with bold headings, replaces the system font.
- Cleaner buttons, cards and pills throughout. The theme colour now only highlights what's
  active or hovered, and soft glows replace the hard outlines.
- **Settings redesigned:** real on/off switches, step sliders, colour swatches,
  button-binding chips, and option pickers where you point at the choice you want.
- **SMB share editor redesigned** as a clear two-column form with Guest /
  Username & Password sign-in.

### ⌨️ New built-in keyboard
- Text entry (SMB shares, rename) now uses Pixel VR Player's own keyboard instead of the
  SteamVR system keyboard. It no longer gets stuck, closes by itself, or interferes with
  the Steam menu.
- QWERTY plus a **?123** symbols page, Shift, Delete, Space and cursor keys.
- **Point into the text to place the cursor** (hold the trigger and sweep to move it).
  Hold the arrow keys, Delete or the thumbstick to repeat, faster the longer you hold.
- **B** always cancels text entry.

### 🎬 Playback
- **Resume where you left off:** files reopen at the position you stopped at.
- **Remembered format:** a projection/3D format you pick in the format picker is
  remembered for that file.
- **Timeline preview:** point at the timeline to see a preview frame of that moment.
- **New format option:** VR 360° 3D (Top-Bottom) in the format picker.
- Hidden-vault files are never recorded in the resume/format history.

### 📁 Files & downloads
- **Sort** folders and files by **Name**, **Newest** or **Largest** (new header button).
- **Per-download Pause / Resume and Cancel** buttons, plus **Remove** for finished items.
  Clicking a queued download no longer cancels it by accident.

### 🔧 Fixes
- **Recenter keeps your screen distance:** it re-aims the screen without resetting the
  distance you set with the thumbstick.
- The **Default Screen Distance** setting now applies correctly; before, each click jumped
  further than the label said, and the value wasn't used at startup.
- **"Follow Gaze" in 180°/360° videos** works properly; the panel was previously mirrored
  to the wrong side.
- After playback stops (including when the vault locks), the menus correctly return to
  normal mode instead of behaving as if a 180°/360° video were still playing.
- Fixed the download confirmation buttons' click areas, and Lock Vault on the Downloads
  page.
- A corrupted settings file no longer stops the app from starting.
- Removed duplicate controls: Recenter, Projection / 3D format, View mode and Lock Vault
  each now live in one place.
- Faster rendering: text is drawn in batches, and the two eyes are rendered with more
  overlap.

### ⚙️ Notes
- Settings you may look for: **Projection / 3D format** is now only in the playback
  format picker (**PROJ** button); **Browser view mode** is the **View** button in the file
  browser header.
- The resume history is stored in `~/.config/pixelvr/playback_state.tsv` and is kept when
  you update.
