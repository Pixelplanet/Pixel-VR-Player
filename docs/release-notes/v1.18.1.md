## Pixel VR Player v1.18.1: scripts next to vault films work again

### 🔐 Vault
- **Scripts next to vault films are found again** (e.g. `8 Mile.funscript` next to `8 Mile.mkv`). Since the
  vault encryption in v1.18.0 the player looked for scripts under the random `.pvrv` file name, so
  plugins such as Funscript found nothing for vault films. They are now matched by the film's real
  name, and are still handed only to plugins you allowed to "Use with vault videos".
- **Encrypted files outside the vault stay private:** an encrypted file in a folder moved out of the vault
  (and any encrypted script next to it) is treated as a vault item, so plugins without "Use with vault
  videos" never see its name or contents.
- A vault film renamed and played again is reported to plugins under its new name, so a script that now
  matches is found.
