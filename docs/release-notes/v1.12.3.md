## Pixel VR Player v1.12.3 — update fix

### 🔧 Updating works again
- The **Update Pixel VR Player** icon failed with `syntax error near unexpected token '<'`.
  The updater replaced its own script while it was still running, so the shell read the new
  file from the wrong place. Scripts are now swapped in as new files, so updates run through
  to the end (Steam entry and the final message box included).

> [!NOTE]
> Coming from v1.12.1 or v1.12.2? Your installed updater still has the bug, so this one
> update may show the error once. The new files are installed anyway — or run
> **Install Pixel VR Player** from the downloaded release instead. Later updates are fine.

### 🖥 Multiple screens on by default
- New installs start with **Multiple Screens** enabled. Existing installs keep their setting
  (Settings → Multiple Screens).

SFTP and WebDAV shares (new in v1.12.0) are still untested on real servers — please
[report problems](https://github.com/Pixelplanet/Pixel-VR-Player/issues) with your server
type, what you did, and `~/pixelvr-run.log`.
