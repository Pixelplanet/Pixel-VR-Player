## Pixel VR Player v1.18.0: encrypted vault, SD cards, a tidier file browser

### 🔐 Encrypted vault
- **Vault files are now encrypted** (AES-256) and their names hidden: on disk they are random `.pvrv`
  files, so nothing can be read or recognised without the player and your unlock combination.
- **Fast:** encryption uses the Steam Frame's built-in AES hardware (several GB per second per core), so
  several vault films can play at once, with seeking, scrub preview and thumbnails as before.
- **Your existing vault is converted automatically** after the first unlock with this version, in the
  background, one file at a time. Each original is deleted only after its encrypted copy was checked.
  The progress is shown under **Settings › Vault & Privacy**.
- **Moving files into and out of the vault** now runs in the background with progress in the status line;
  the player no longer freezes (and the vault no longer locks itself) during large moves.
- **Changing the combination** re-protects the key; files don't need to be re-encrypted.
- **Forgot the combination?** It is written down in `PixelVRPlayer/logs/session.dat`
  (shown under Settings › Vault & Privacy).
- Scripts next to vault films (e.g. `.funscript`) are found by their real names and handed decrypted only
  to plugins you allowed to "Use with vault videos".
- **Bookmarks to vault folders are hidden** while the vault is locked.

### 💾 SD cards
- An inserted SD card appears in the file browser's home folder, with its free space.
- **Download Folder › SD card** saves downloads to `Downloads` on the card (falls back to `~/Downloads`
  while no card is inserted). The setting shows the free space at the destination.

### 📁 File browser
- **Two-row header:** the folder path has the whole top row; the buttons sit below with short captions
  ("Sort by", "View").
- **Clickable folder path:** click any level of the path to jump there, also on network shares.
- **New folder:** "+ Folder" creates a folder in the current local folder, SD card or vault.
- **Bigger cards:** less empty space under the header and between cards; Large view shows titles on two
  lines.
- **Correct format badges:** 3D films without "3D" in the name now show **3D SBS** / TB / FS, taken from the
  file's 3D tag or the picture check (as playback does); a format you picked by hand is shown too. Flat
  videos show just their resolution (1080p, 4K, ...).
- The page arrows and the Up button are gone: the scroll bar, ".. (up)" and the clickable path replace them.

### ⌨️ Keyboard
- Password fields have a **Show / Hide** button to check what you typed.
