## Pixel VR Player v1.12.0 — Plex in original quality, SFTP & WebDAV shares

> [!NOTE]
> **SFTP and WebDAV shares are new and untested on real servers.** They were tested on the
> headset against local test servers only; SMB is unchanged. If you use them, please
> [report any problem](https://github.com/Pixelplanet/Pixel-VR-Player/issues) — server type
> (Mac, Linux, Synology, Nextcloud, …), what you did, and `~/pixelvr-run.log` help a lot.

### 🎞 Plex — keep Plex's interface, play the original file
- New **Plex** shortcut (*Settings › UI & Appearance › Shortcuts*) opens Plex Web on a screen.
- Press play on a film or episode and it plays in Pixel VR Player itself: the **original file,
  hardware-decoded**, in full quality (4K HEVC, all audio and subtitle tracks, chapters, 3D
  detection) instead of Plex's browser transcode. It starts at Plex's resume point.
- **Stop or Close returns you to the same Plex page** — a hint above the control panel says so.
  The page stays with its screen, so moving or re-arranging screens while you watch is fine.
- Your watched position is reported back to Plex, so *Continue Watching* stays right.
- Only a click on Plex's play / resume controls hands a video over: opening Plex (or a second
  Plex window) no longer starts the last item by itself, and two windows never play the same item.
- Dropped connections from the Plex server are resumed instead of causing artefacts or stalls.
- Your Plex sign-in token never appears in logs, recents or playback history.

### 🌐 Network: SFTP and WebDAV next to SMB
- The file browser's **SMB Shares** section is now **Network**.
- Add **SFTP** servers (any Mac or Linux machine with Remote Login / SSH) and **WebDAV**
  servers (http or https — Nextcloud, Synology, QNAP, …). Pick the type with the new buttons
  in the share editor; there is a Port field, and for SFTP an empty folder means your home folder.
- Browse, stream (with read-ahead, like SMB) and download exactly like SMB shares. SFTP uses
  your SSH key or password and remembers each server's key on first connection (a changed key
  is refused). Credentials are stored encrypted like SMB ones.
- Uses the system's libssh / libcurl that SteamOS ships.

### 🖥 Web browser
- **Keyboard in sign-in forms embedded in a page** (Plex, Google, Apple, PayPal logins).
- **Enter in the address bar** navigates and closes the keyboard.
- Pages get the **dark colour scheme**, and pages are drawn in software, which fixes sites with
  translucent panels (Plex Web showed white panels with unreadable text).
- Opening a shortcut or the browser while a 180°/360° video plays replaces the video directly
  (it used to ask for a screen and then fail for lack of decoder capacity).

### 🎯 Laser and controls
- The **laser beam** is now part of the sharp layer system: hidden behind panels, visible in
  front of them, instead of vanishing in front of every panel.
- No more second cursor circle or a laser "caught" at the edge of the control panel; the
  cursor dot on curved screens is no longer cut in half.
- The control panel no longer cuts a strip out of the screen above it.
- In **180°/360° videos** tilting and zooming with the right stick keeps the UI hidden.
- The *Audio follows selection* tooltip is no longer cut off.

### 📦 Installing
- The README has a new, easiest way: download the release in the headset's own browser,
  extract it in Dolphin and double-click **Install Pixel VR Player**.
