## Pixel VR Player v1.12.1 — installer fixes

A fix-up release for the installer; the player itself is the same as
[v1.12.0](https://github.com/Pixelplanet/Pixel-VR-Player/releases/tag/v1.12.0) (Plex in
original quality, SFTP & WebDAV shares, …). If v1.12.0 installed fine for you, there is
nothing new here.

> [!NOTE]
> SFTP and WebDAV shares (new in v1.12.0) are still untested on real servers — please
> [report problems](https://github.com/Pixelplanet/Pixel-VR-Player/issues).

### 📦 Installing from the headset is now straightforward
- **Shows up in your Steam library right away.** The installer now adds the game through
  Steam itself (SteamOS's "Add to Steam"), so it appears without restarting Steam — and
  with its library artwork, which earlier installers never actually installed.
- **Always installs to `~/PixelVRPlayer`.** The release folder no longer contains an
  *Update* icon next to *Install*; running it from a copied folder (e.g. on the Desktop) used
  to install the app *into that folder*.
- **No "Press Enter to close".** There's no Enter key on the controller — install and update
  now end with a message box you can click **OK** on. Everything is logged to
  `~/pixelvr-install.log`, and an error box shows the last lines of it.
- **README:** the steps that work on SteamOS — download in the browser, double-click the
  `.tar.gz` in Dolphin (it opens like a folder), drag `PixelVRPlayer` to the Desktop,
  double-click **Install Pixel VR Player**. Right-click in Desktop Mode is **pressing the
  thumbstick down**.

### How to install
1. Desktop Mode → browser → download **`pixelvr-linux-arm64.tar.gz`** from this release.
2. Dolphin → **Downloads** → double-click the file (pick Dolphin if asked).
3. Drag the **`PixelVRPlayer`** folder onto the Desktop, open it, double-click
   **Install Pixel VR Player** (choose *Execute*), click **OK**.
4. Back to Gaming Mode: **Pixel VR Player** is in your library. You can delete the folder on
   the Desktop.
