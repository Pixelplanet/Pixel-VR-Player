## Pixel VR Player v1.16.0: plugins

### 🧩 Plugins
- **New Plugins tab in Settings.** Plugins add connections to devices, other apps and services. Each
  installed plugin has one line: a switch to turn it on or off, its status, **Edit** for its settings,
  and **Remove** (asks once more).
- **Install plugins** (top right of the Plugins page) lists the plugins from the official plugin
  repository, each with a plain explanation of what it does and how to use it. New plugins start
  switched off.
- **Updates:** a plugin with a newer version shows a **green arrow**. Press it to see what's new, then
  update with one press. Every download is checked before it is installed.
- A `.pvrplugin` file in your **Downloads** folder also shows up on the Plugins page, ready to install.
- Plugins can show an **intensity graph** above the timeline (for example where a script is calm or
  intense) and their status on the Plugins page.
- Plugins run as separate programs and only get what they ask for: no passwords, logins or browser
  data, and nothing about videos in your private vault unless you allow it per plugin.

### Available plugins
- **Funscript devices:** plays the `.funscript` that belongs to a video on devices connected to
  [Intiface Central](https://intiface.com/central/), in sync with the video.
  - Finds Intiface on your network with one press.
  - Devices fade out while you scrub (or keep running, your choice), and pause when you pause or take
    the headset off.
  - Picks up again by itself when the connection to Intiface drops.
  - Works with local files, network shares, **Plex** and **Jellyfin**: put the script next to the video,
    or into the new **Funscripts** folder inside the PixelVRPlayer folder.
- **Sync with MultiFunPlayer / XBVR (DeoVR protocol):** for people who already control their devices
  from MultiFunPlayer, ScriptPlayer, FunFlixDroid or XBVR. Those apps follow the video playing in Pixel VR
  Player like they follow DeoVR.

Missing a plugin? Request it, or write your own, in the
[plugin repository](https://github.com/Pixelplanet/Pixel-VR-Player-Plugins): it has the developer
documentation, an SDK and an example plugin.

### 🗂️ Tidier folders
- Everything the player keeps for you is inside its own folder: **PixelVRPlayer/logs** for the logs and
  **PixelVRPlayer/Funscripts** for scripts. Logs from the home folder are moved there automatically.
- New installs download to your system **Downloads** folder (your own choice is kept).
- Uninstalling keeps your Funscripts folder if it has scripts in it.

### Smaller changes
- Jellyfin and Plex videos report their real file name to plugins (never any server address or login).
